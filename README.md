# Art Time — arttime-c2-sculpture-gallery

[Open the website](https://sadikovsa.github.io/arttime-c2-sculpture-gallery/).

Approved alternative design for Art Time, Tashkent. Static HTML/CSS/JavaScript, local images and fonts; no build step. Serve `dist/` with a local HTTP server. GitHub Pages serves the contents of `dist/` from the `gh-pages` branch.

Catalog: 16 researched items, five decorating examples and two brand interior ideas. Price and availability require confirmation. Address: Ташкент, ул. Тимура Малика, 3А. Phone: +998 98 000 00 48. Instagram: https://www.instagram.com/arttime_uz/.

Product sharing opens the selected item using `?product=<id>#catalog`. Request text is editable and prepared locally; copy or download it, then contact Art Time. No automatic delivery and no personal data in browser storage.

This client design alternative uses `noindex,follow`. Metadata uses its own Pages project URL. `robots.txt` in a project directory does not control the GitHub host root. Original native checkpoint is preserved in Git history; `.openai` deployment identity is removed from this distribution.

SEO/QA evidence: `.studio/`. All three final source snapshots and full release evidence are archived in the private Codex Studio case.
